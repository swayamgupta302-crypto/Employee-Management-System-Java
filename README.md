Employee Management System

A simple and beginner-friendly Employee Management System developed using Java.

📌 About the Project

This project is a basic console-based application that allows the user to:

- Add employee details
- Display employee details
- Exit the program

The project is created to demonstrate basic Java programming concepts such as classes, objects, methods, loops, and switch-case statements.

🛠️ Technologies Used

- Java
- Scanner
- Object-Oriented Programming (OOP)

✨ Features

1. Add Employee
2. Display Employee
3. Exit

▶️ How to Run

Using Command Prompt / Terminal

Clone the repository:

git clone https://github.com/swayamgupta302-crypto/Employee-Management-System-Java.git

Go inside the project folder:

cd Employee-Management-System-Java

Compile the program:

javac EmployeeManagement.java

Run the program:

java EmployeeManagement
